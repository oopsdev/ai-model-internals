11. CNN 卷積

影像若用「全連接」硬做：一張 224×224×3 的圖攤平就是 15 萬維，第一層每個神經元就要 15 萬個權重——參數爆炸，還把「相鄰像素才相關」「同物件換位置仍是同物件」這些影像特性全丟了。卷積 (convolution) 就是為影像量身打造的解法。

11.1 卷積在做什麼（定義）

一個卷積核 (filter / kernel) 是一個小方陣（如 3×3）的權重。它滑過整張影像，在每個位置把 filter 蓋在對齊的小塊上，做逐元素相乘再加總（＝一次內積，§1.1）得到一個數；所有位置的數排起來就是一張特徵圖 (feature map)。

以符號寫（輸入影像 $I$、卷積核 $K$ 大小 $F\times F$、偏置 $b$、輸出特徵圖 $O$）：

$$O(i,j)=\underbrace{\sum_{u=0}^{F-1}\sum_{v=0}^{F-1} K(u,v)\,I(i{+}u,\,j{+}v)}_{\text{filter 與小塊逐元素相乘加總}}\;+\;b$$

這正是卷積核 $K$ 與該位置小塊 $P_{ij}$（$I$ 在 $(i,j)$ 的 $F\times F$ 區域）的 Frobenius 內積（＝把兩者攤平做內積，§1.1）：

$$O(i,j)=\langle K,\,P_{ij}\rangle + b=\sum_{u,v}K_{uv}\,(P_{ij})_{uv}+b$$

多通道（輸入有 $C$ 個通道，如 RGB $C=3$）時，再對通道加總：

$$O(i,j)=\sum_{c=1}^{C}\sum_{u=0}^{F-1}\sum_{v=0}^{F-1} K_c(u,v)\,I_c(i{+}u,\,j{+}v)+b$$

注意：一步卷積 = 內積（一個數），不是矩陣×矩陣（後者結果是矩陣）。

小註（名詞精確性）。 嚴格數學的「卷積」會把核翻轉；深度學習慣稱的「卷積」其實是不翻轉的互相關 (cross-correlation)（上式即是）。因為核是學出來的、翻不翻轉學到的權重會自動吸收，效果等價，所以沿用「卷積」這個名字。

用數字算一次（3×3 卷積 = 9 維向量的內積）。 把 filter 與小塊各攤平成 9 維向量，做 $(1\times9)\cdot(9\times1)$ 的內積：

攤平來看：$K=(1,2,3,4,5,6,7,8,9)$、$P=(1,0,1,0,1,0,1,0,1)$，內積 $=1{\cdot}1+2{\cdot}0+3{\cdot}1+4{\cdot}0+5{\cdot}1+6{\cdot}0+7{\cdot}1+8{\cdot}0+9{\cdot}1=1+3+5+7+9=25$——和上圖一模一樣。所以 3×3 卷積一步 = 9 維向量的內積 = 一個數。

11.2 幾何意義：filter 是「樣板」、特徵圖是「對齊強度圖」

接回 §1.1（內積＝對齊程度）與 §1.2（神經元＝特徵偵測器）：

  • filter 就是一個「局部樣板」（小塊空間裡的一個方向向量）。
  • 每個位置的卷積＝量「這一小塊有多像這個樣板」（對齊程度 / 投影）——越像、數值越大（激活越強），不像則接近 0 或負。
  • 所以整張特徵圖 = 「這個樣板在影像各處出現的強度分佈圖」（像一張 heat map）。

用神經元的語言說：filter = 神經元的權重 $\mathbf{w}$；特徵圖上每一格 = 卷積在該位置的輸出（內積 + 偏置 $z=\text{filter}\cdot\text{小塊}+b$；過激活如 ReLU 後才是 $a=\sigma(z)$）；整張特徵圖 = 同一個神經元（共用同一組權重）掃過全圖的輸出圖（過激活後即 activation map）——這就是 CNN 的權重共享 (weight sharing)（全連接是每個神經元各有獨立權重；CNN 是「一個神經元掃全圖」）。多個 filter → 多張特徵圖 = 多個不同「特徵偵測神經元」各自的響應圖。

特徵圖維度 ≠ 獨立神經元數（別套用全連接的直覺）：特徵圖 $7\times7$ 是「該 filter 掃過的位置數 / 輸出數」（49 個），但這 49 個位置共享同一組權重（filter）——不是 49 組獨立權重。對比：全連接一層的輸出維度 = 神經元數 = 獨立權重組數（每神經元一組），所以「維度 = 神經元數」在全連接成立、在 CNN 不成立——CNN 真正「獨立」的是 filter 數（每個 filter 一組獨立權重）。若這層有 $C_{out}$ 個 filter → 輸出 $7\times7\times C_{out}$，其中獨立權重組數 = $C_{out}$、總輸出單元 = $49\times C_{out}$。

例：一個「垂直邊樣板」filter 掃過影像後，特徵圖會在有垂直邊的地方變亮、平坦處接近 0——等於幫你標出「圖裡哪裡有垂直邊」。這就是卷積的幾何本質：一個到處掃描的特徵偵測器。

淺層 filter 學到邊緣 / 角 / 紋理等低階樣板，多層堆疊後組合成部件、物件等高階樣板——就是「在越來越抽象的樣板空間裡量對齊」（呼應 §1.3.1 逐層換座標）。

filter 是「學出來」的，不是人設計的。 filter 的數值就是權重：一開始隨機初始化，再用梯度下降＋反向傳播訓練（§1.2、§4）。資料與損失會自動逼它長成有用的樣板——淺層自己學成邊緣/角、深層組合成部件/物件，沒有人手動設定「去學邊緣」。（本節與 §11.1 示意圖的 filter 數字是為講解手填的；只有傳統影像處理才用人工設計的固定 filter，如 Sobel、高斯模糊。）

filter 的初始值怎麼來（從零訓練）。 每一層、每個 filter、每個輸入通道的權重都各自獨立隨機抽樣——這樣才能打破對稱 (symmetry breaking)：若同層 filter 初值都一樣，會收到相同梯度、學到一模一樣的東西，多幾個 filter 也是白費。配 ReLU 常用 He 初始化：從變異數 $2/\text{fan\_in}$ 的分布抽，其中一個 filter 的 $\text{fan\_in}=F\times F\times C_{in}$（它的參數數，故不同層的隨機尺度不同）；偏置 $b$ 一律設 0（初始化細節見 §10.1）。例外：用預訓練 / 遷移學習時，部分或全部 filter 是從別的模型（如在 ImageNet 訓練好的）複製來當初始值、再微調（§17），只有新加的層才隨機——此時就不是全部隨機。

11.3 三個關鍵性質（為什麼卷積適合影像）

  • 局部連接（感受野）：每個輸出只看一小塊，符合「相鄰像素才相關」。
  • 參數共享：同一個 filter 掃全圖——不管物件在哪都用同一組權重 → 參數量大減（3×3 filter 只有 9 個權重，卻掃遍全圖）。
  • 平移等變 → 近似平移不變：卷積本身是等變（特徵跟著位置一起移），再靠 pooling / global pooling 把它變成對位置近似不變——所以同一 filter 移到別處仍抓得到、認得出「換位置的同一物件」（嚴格的完整不變需 global pooling）。
  • 多通道：輸入 RGB 有 3 通道、filter 也有對應深度；用多個 filter 就得多張特徵圖（每張抓一種樣式）。

輸入通道 vs 輸出通道。 「通道 (channel)」是影像／特徵圖的深度層數（同一位置疊了幾張圖）：

  • 輸入通道 $C_{in}$：這一層拿到幾張圖疊著。原始 RGB 影像 = 3、灰階 = 1；中間層則 = 上一層輸出的特徵圖張數。
  • 輸出通道 $C_{out}$：這一層有幾個 filter 就輸出幾張特徵圖（一個 filter → 一張），故 $C_{out}$ = filter 數。
  • 每個 filter 的深度 = 輸入通道數：filter 其實是 $F\times F\times C_{in}$，會跨所有輸入通道一起做內積、加總成一張特徵圖。

例：輸入 RGB（$C_{in}=3$）、這層 64 個 filter（每個 $3\times3\times3$）→ 輸出 64 張特徵圖（$C_{out}=64$）；下一層的輸入通道就變成 64。層層相接：上一層的輸出通道 = 下一層的輸入通道。

通道數怎麼決定？

  • 輸入通道：被決定的——第一層由資料定（RGB=3、灰階=1），中間層 = 上一層的輸出通道。
  • 輸出通道（= 這層 filter 數）：由你設計，是超參數（常見 32/64/128/256/512，越深通常越多）。
  • 關鍵區分：filter 的「數值」是訓練學出來的（參數）；filter 的「數量（通道數）」是人設定的（超參數）（接 §6 參數 vs 超參數）。
  • 慣例：越深、通道越多、空間尺寸越小（池化省下的算力換更多通道）；實務多沿用經典架構（VGG、ResNet）再微調，不會每次從零猜。

filter 的三個維度（大小、深度、數量）。 設計一層卷積時，你決定 filter 的「大小」與「數量」，深度自動跟著輸入：

維度是什麼誰決定
大小 $F\times F$每個 filter 蓋多大一塊（感受野）你選（超參數）：3×3、5×5…
深度 $C_{in}$每個 filter 的厚度被決定 = 輸入通道數
數量 $C_{out}$這層有幾個 filter你選（超參數）= 輸出通道數

每個 filter 其實是 $F\times F\times C_{in}$ 的立體塊（只有輸入單通道時才剛好是一片 2D 方陣）。

例：輸入 RGB（$C_{in}=3$），設計「這層放 64 個 5×5 filter」：每個 filter = $5\times5\times3$、共 64 個 → 輸出 64 張特徵圖（$C_{out}=64$）；參數量 $=(5\times5\times3+1)\times64=(75+1)\times64=76\times64=4864$。

訓練後留下什麼。 CNN 訓練的淨結果 = 所有卷積 filter（＋偏置）＋ 全連接分類頭的權重（＋偏置）（可能還有 BatchNorm 參數）——這一整包就是模型參數（幾 B 參數的那個參數），存進模型檔、推論時固定使用。前半是「特徵抽取器」、後半是「分類頭」。

各架構的參數組成（本質相同、種類不同）。 「模型參數」的本質一致——凡是訓練時被梯度下降更新的數字都算；但組成因架構而異，CNN 的 filter 只是其中一種形式：

架構主要參數
MLP / 全連接每層權重 $\mathbf{W}$ + 偏置 $\mathbf{b}$
CNN卷積 filter + 偏置、FC 頭權重 + 偏置、BatchNorm $\gamma,\beta$
RNN / LSTM輸入權重 $\mathbf{W}_x$、隱藏權重 $\mathbf{W}_h$、偏置；LSTM 各閘門的 $\mathbf{W},\mathbf{b}$
Transformer / LLMEmbedding 表、注意力 $\mathbf{W}_Q/\mathbf{W}_K/\mathbf{W}_V/\mathbf{W}_O$、FFN 兩層、LayerNorm $\gamma,\beta$、輸出頭

不算參數的：超參數（層數、維度、學習率——人設，不存權重檔，§6）、無參數的層（ReLU、pooling、dropout；少數如 PReLU 例外）、優化器狀態（Adam 的動量 $m,v$——訓練時要，但非模型本身，§5）。一句話：任何模型的參數都是「所有可學的權重＋偏置（＋少數可學係數如 $\gamma,\beta$、embedding 表）」的集合，由訓練學出、存檔、推論固定使用。

11.4 stride、padding 與輸出尺寸

  • stride（步幅）：filter 每次滑幾格（越大、輸出越小）。
  • padding（補邊）：在影像邊緣補 0，用來保住尺寸或照顧邊界像素。
  • 輸出邊長 $=\dfrac{W-F+2P}{S}+1$（$W$ 輸入邊長、$F$ filter 邊長、$P$ padding、$S$ stride）。

例（stride 的影響） 輸入 5×5、filter 3×3、$P=0$：

  • $S=1$：$\frac{5-3+0}{1}+1=3$ → 輸出 3×3（每格都掃、重疊最多）。
  • $S=2$：$\frac{5-3}{2}+1=2$ → 輸出 2×2（跳著掃、尺寸砍半 ＝ 下採樣；常用來取代池化）。

例（padding 的影響） 輸入 5×5、filter 3×3、$S=1$：

  • $P=0$（valid，不補）：$\frac{5-3}{1}+1=3$ → 輸出 3×3（每層縮小、邊界像素被掃到少）。
  • $P=1$（same，四周各補一圈 0 → 變 7×7）：$\frac{5-3+2}{1}+1=5$ → 輸出 5×5（保持原尺寸、邊界也能當中心被掃到）。

直覺：stride 控「掃多快」（越大輸出越小、下採樣）；padding 主要用來保持尺寸（same padding 取 $P=\frac{F-1}{2}$）並照顧邊界像素。

11.5 整張卷積 = 一次矩陣乘法（im2col）

雖然一步是內積，整張卷積可重排成一次大矩陣乘法：把每個小塊攤平成一列、堆成大矩陣 $\mathbf{X}_{\text{patches}}$，filter 攤平成 $\mathbf{W}$，一次 $\mathbf{X}_{\text{patches}}\mathbf{W}^\top$（GEMM）就算出整張特徵圖。這叫 im2col，也是 GPU/NPU 加速卷積的方法（§20）——所以「卷積本質是矩陣乘法」指的是這個整體，不是那兩個小方陣直接相乘。

工程意涵。 卷積不只用在影像：1D 卷積掃封包大小/方向序列，可抓「加密流量的局部指紋」（網路 AI 常用、輕量、適合邊緣 NPU）。多數邊緣 NPU 本來就為 CNN 卷積最佳化，所以 1D/2D-CNN 在邊緣跑很划算。

11.6 各種「維度」誰決定（對照 embedding 的向量維度）

CNN 沒有 embedding 那種單一「向量維度 $d$」，而是多種尺寸並存、來源不同：

維度 / 尺寸是什麼誰決定
輸入 $H\times W\times C$影像 高×寬×通道（RGB=3）資料（常 resize 到固定值＝預處理，人設）
filter 大小 $F\times F$卷積核尺寸（3×3…）人為（超參數）
filter 數量 ＝ 輸出通道 $C_{out}$這層學幾種特徵人為（超參數）
stride / padding滑動步長 / 補邊人為（超參數）
輸出特徵圖 $H'\times W'$每張特徵圖尺寸計算推導（§11.4 公式）
filter 裡的權重值每個核的數字訓練學（參數）
flatten 後向量長度進全連接層的維度計算推導（$H'\times W'\times C'$）
FC 輸出 ＝ 類別數最後輸出幾類任務決定

最類比 embedding「向量維度 $d$」的是「通道數 $C$」：CNN 中每個空間位置 $(h,w)$ 跨所有通道，就是一個長度 = 通道數的向量（那個位置的「特徵向量」）。這個通道數（＝上一層 filter 數 $C_{out}$）跟 embedding 的 $d$ 一樣，是訓練前定好、固定的超參數（§13、§6）。差別：CNN 還多了空間尺寸 $H'\times W'$ 這種由公式算出來的維度（embedding 沒有）；訓練學的一樣只是值（filter 權重），不是維度。

11.7 哪些應用適合用 CNN（為什麼）

CNN 適不適合，取決於資料與問題是否符合它的「內建假設」（inductive bias）。符合 → 事半功倍、參數少又準；不符合 → 換別的架構更好。

CNN 的內建假設適合的資料 / 問題特徵為什麼例子
局部性（filter 只看小窗）有意義的特徵是局部的filter 專抓局部樣式（§11.2）影像的邊/紋理；封包序列的局部指紋
平移不變（同 filter 到處滑）特徵可能出現在任何位置、意義相同權重共享 → 位置無關偵測貓在畫面任何角落都認得
權重共享（參數少）輸入維度高、需省算力/抗過擬合一個小 filter 重複用遍全圖百萬像素影像
階層組合（堆疊）資料有由小組大的組合結構低階特徵疊成高階像素→邊→形狀→物件
網格結構資料在規則網格上、鄰近相關卷積定義在網格鄰域1D 序列、2D 影像、3D 影音

適合的應用：影像分類 / 物件偵測 / 分割、瑕疵檢測、OCR、音訊（轉頻譜圖當影像）、醫療影像；1D-CNN 掃時序 / 封包序列（抓局部指紋）。

關於「長度不定」的序列（如封包流）。 要先分清兩種「不定」：① 封包大小（bytes 數）當特徵值 → 只是輸入數字不同，CNN 本來就吃任意值，無妨；② 封包數量（序列長度）不定 → 才是重點，而 CNN 有解：卷積本身不限長度（同 filter 滑過任意長度、輸出跟著變），只有最後接全連接分類頭才需固定大小 → 用 global pooling（全域池化，對整條時間軸取 max/avg） 把不定長特徵圖壓成固定向量，或取固定窗口（前 N 個 / 滑動窗）即可。原生吃不定長是 RNN 的先天優勢（§14）；1D-CNN 則靠 global pooling / 固定窗達成。實務常串接：CNN 抽局部特徵 → pooling 或 RNN 聚合。

不適合的情況（對照）：

  • 表格資料（欄位無空間鄰近、順序可任意打亂）→ 局部性/平移不變假設失效，用樹模型（GBDT，見 附錄 C）或 MLP 更好。
  • 長距離、任意位置的關聯（語言長依賴）→ CNN 感受野有限，用 Transformer / 注意力（§15）。
  • 非規則圖結構（社群網路、分子）→ 沒有網格，用 GNN。

工程意涵。 判別式 ML 的邊緣部署很吃 CNN 的特性：1D-CNN 掃封包大小 / 方向序列抓「加密流量局部指紋」、2D-CNN 做影像瑕疵 / 監控——都因參數少、平移不變、邊緣 NPU 為卷積最佳化而輕量好落地。反之，需長依賴或無網格結構的任務要換架構。

11.8 完整範例：深度-5 CNN（超參數 + 維度追蹤 + 參數量）

把 §11.4（尺寸公式）、§11.6（誰決定）、§7（參數量）串成一個具體例子。任務：32×32 RGB 影像分 10 類。深度 5 = 5 個有權重的層（池化 / ReLU / dropout 無權重，不算深度）：3 卷積 + 2 全連接。

層類型超參數（人設）輸出維度（公式算）
—輸入（資料）32×32×332×32×3
L1Conv3×3、$C_{out}$=32（32 個 filter，每個 3×3×3）、s=1、p=1 → ReLU → MaxPool 2×232×32×32 → 16×16×32
L2Conv3×3、$C_{out}$=64（64 個 filter，每個 3×3×32）、s=1、p=1 → ReLU → MaxPool 2×216×16×64 → 8×8×64
L3Conv3×3、$C_{out}$=128（128 個 filter，每個 3×3×64）、s=1、p=1 → ReLU → MaxPool 2×28×8×128 → 4×4×128
—Flatten—2048（=4·4·128）
L4全連接神經元 256 + Dropout 0.5256
L5全連接（輸出）神經元 = 類別數 10 → softmax10

（尺寸用 $(W-F+2P)/S+1$：如 L1 $(32-3+2)/1+1=32$。）全域超參數：$\eta$=0.001、batch=64、epoch 上限=50（+早停）、Adam、weight decay $\lambda$=1e-4、dropout=0.5、MaxPool 2×2。

三類數字（呼應 §11.6）：

  • 超參數（人設、可自由調）：filter 大小、每層 $C_{out}$（32/64/128）、stride、padding、FC 寬度 256、深度=5、$\eta$ / batch / epoch / dropout / $\lambda$ / pool 大小。
  • 計算決定（公式算出、不能亂填）：特徵圖尺寸 32→16→8→4、flatten 長度 2048。
  • 資料 / 任務決定：輸入 32×32×3（資料）、輸出 10（類別數）。

參數量 ≈ 62 萬（Conv 每層 $(F^2C_{in}+1)C_{out}$、FC $(\text{輸入}+1)\times\text{輸出}$）：

層計算參數
L1$(3^2{\cdot}3+1){\cdot}32$896
L2$(3^2{\cdot}32+1){\cdot}64$18,496
L3$(3^2{\cdot}64+1){\cdot}128$73,856
L4$(2048+1){\cdot}256$524,544
