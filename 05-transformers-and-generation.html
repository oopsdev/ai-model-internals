15. 注意力與 Transformer

RNN（§14）逐步計算、難平行、長距弱。注意力 (attention) 讓序列裡每個位置能一次看其他位置、平行算完。（encoder 可看整條序列；自迴歸 decoder（生成） 要加 causal mask——每個位置只能看自己與之前的 token、不能看未來，§15.2、§16。）本章先講注意力公式（§15.1），再從 token ids 一路追到 vocabulary logits（§15.2），最後說明訓練目標（§15.3）與計算成本（§15.4）。

15.1 注意力機制

每個位置產生 query $\mathbf{q}$、key $\mathbf{k}$、value $\mathbf{v}$。用 query 跟所有 key 做內積（＝對齊程度，§1.1）得分數，過 softmax（§3.3）變權重，再對 value 加權平均：

$$\text{Attention}(Q,K,V)=\text{softmax}\!\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$

直覺：每個 token 問「我該關注誰」——跟誰的 key 越對齊（內積大），就給越高權重、把它的 value 拿更多。這是「內容相關的動態加權平均」。整個機制全是前面的數學：內積（§1.1）＋ softmax（§3.3）＋ 矩陣乘法（§1.3）。除以 $\sqrt{d_k}$（$d_k$＝key 維度）是縮放：$QK^\top$ 是 $d_k$ 項相乘相加、其方差隨 $d_k$ 增長，不縮放會讓 softmax 過度集中（飽和）、梯度變小、訓練不穩。

為什麼強：可平行（整個序列一次算）、長距（任兩位置直接相連）、易堆疊 → 成為 LLM 的骨幹。

15.2 從 token ids 到 vocabulary logits：完整資料流與 shape

以 decoder-only LLM 為例，用一組小尺寸追一次（$B$＝batch、$n$＝序列長度、$d_\text{model}$＝每個 token 的向量維度、$h$＝頭數、$d_\text{head}=d_\text{model}/h$、$d_\text{ff}$＝FFN 中間維度）：

B=1, n=4, d_model=8, h=2, d_head=4, d_ff=32, 詞表大小 |V|
步驟運算shape
0. token idstokenizer 輸出（§12）[1, 4]
1. embedding lookup查表 $E$（大小 $|V|\times 8$），每個 id 取一列（§13.1）[1, 4, 8]
2. 加入位置資訊注意力本身不分先後，需補位置：例如加上絕對位置 embedding（RoPE 等方法則不在這一步加，而是在步驟 4 之後對 Q、K 旋轉，不改 shape）[1, 4, 8]
3. LayerNorm（Pre-LN）每個 token 的 8 維各自正規化（§10）[1, 4, 8]
4. QKV 投影$Q=XW_Q,\ K=XW_K,\ V=XW_V$，三個 $W$ 各 $8\times 8$，都是學出來的參數各 [1, 4, 8]
5. 拆成多頭8 維切成 $h=2$ 頭 × $d_\text{head}=4$，並把頭的軸移到前面各 [1, 2, 4, 4]
6. 注意力分數每頭算 $QK^\top/\sqrt{4}$：4 個位置兩兩計分[1, 2, 4, 4]
7. causal mask在 softmax 之前把「未來位置」的分數設為 $-\infty$[1, 2, 4, 4]
8. softmax每列歸一化成權重，和為 1（§3.3）[1, 2, 4, 4]
9. 加權 V權重 × $V$：每個位置得到上下文的加權平均[1, 2, 4, 4]
10. concat + $W_O$兩頭拼回 8 維，再乘輸出投影 $W_O$（$8\times 8$）[1, 4, 8]
11. 殘差$X \leftarrow X+\text{Attn}(\text{LN}(X))$[1, 4, 8]
12. FFNLN → 升維 $8\to 32$ → 激活（如 GELU，§8）→ 降維 $32\to 8$，再加殘差[1, 4, 8]
（步驟 3–12 重複 $N$ 層）每層 shape 不變，參數各自獨立[1, 4, 8]
13. final norm最後一個 LayerNorm[1, 4, 8]
14. LM head乘 $W_\text{out}$（$8\times |V|$），每個位置得到對整個詞表的分數[1, 4, |V|]
15. softmax生成時只取最後一個位置的 logits 轉成下一個 token 的機率（§16）[1, |V|]

（此例 $n$ 與 $d_\text{head}$ 剛好都是 4，所以 Q 與 $QK^\top$ 的 shape 數字相同，但軸的意義不同：Q 是 [batch, 頭, 位置, 頭內維度]，$QK^\top$ 是 [batch, 頭, 查詢位置, 被看位置]。）

幾個容易弄錯的點：

  • Q、K、V 是投影出來的：同一個輸入 $X$ 乘三個不同的可學矩陣，得到三種「角色」——Q 用來發問、K 用來被比對、V 是被取用的內容。
  • 多頭 (multi-head)：把 $d_\text{model}$ 切成 $h$ 份，各頭在較小的子空間裡學不同的關注模式，最後 concat 再乘 $W_O$ 混合；總計算量與單頭全維度相近。
  • causal mask 加在 softmax 之前的分數上：把未來位置設為 $-\infty$，softmax 後權重自然是 0，且每列和仍為 1。若在 softmax 之後才把權重歸零，每列和就不再是 1。
  • Pre-LN vs Post-LN：原始 Transformer 用 Post-LN：$x\leftarrow\text{LN}(x+\text{Sublayer}(x))$；多數現代 LLM 用 Pre-LN：$x\leftarrow x+\text{Sublayer}(\text{LN}(x))$，並在最後加 final norm。Pre-LN 讓殘差路徑保持暢通，深層訓練通常較穩定。不少模型也以 RMSNorm 取代 LayerNorm。
  • 殘差連接：每個子層（注意力、FFN）都是「輸入 + 子層輸出」，梯度可沿殘差路徑直接回傳（§9）。
  • FFN：對每個位置各自做「升維 → 激活 → 降維」，位置之間不交換資訊（交換資訊是注意力的工作）。
  • weight tying：輸入的 embedding 矩陣 $E$（$|V|\times d$）與輸出的 LM head $W_\text{out}$（$d\times|V|$）可以共用同一組參數（$W_\text{out}=E^\top$），省下大量參數；是否共用依模型而定。

15.3 訓練目標：shifted targets 與 next-token loss

LLM 預訓練的目標是「每個位置預測下一個 token」。把同一段文字錯開一格當標準答案：

輸入   : t1  t2  t3  t4
目標   : t2  t3  t4  t5
  • 位置 $i$ 的 logits 與目標 $t_{i+1}$ 算 cross-entropy（§3.3），所有位置的損失取平均。
  • 因為有 causal mask，位置 $i$ 看不到 $t_{i+1}$ 之後的內容，所以一次前向就能平行訓練所有位置（teacher forcing），不必逐字生成。
  • 推論時則只有最後一個位置的預測會被拿來取樣（§16）。

15.4 計算成本：訓練 / prefill vs decode

  • 訓練 / prefill（一次處理整段輸入）：標準注意力要讓 $n$ 個位置兩兩計分，形成 $n\times n$ 的關係，時間通常為 $O(n^2)$ 量級。是否在記憶體中保存完整的 $n\times n$ 矩陣則依 kernel 與實作而異（例如 FlashAttention 分塊計算，不保存完整矩陣）。
  • decode 單步（生成一個新 token）：只需算新 token 的 $\mathbf q$，再與 KV cache 中既有 $n$ 個位置的 K、V 計分。每層的計算與讀取量隨既有 context 長度近似線性增加；不會每步重建完整的 $n\times n$ 矩陣。
  • 連續生成多個 token：每一步都比上一步多看一個位置，累積成本仍隨總長度快速增加。
  • KV cache 容量隨序列長度線性增加，也依層數、KV head 數、head 維度、batch 與資料型別而增加：

$$\text{KV cache bytes}\approx 2\times L\times n_\text{kv}\times d_\text{head}\times n\times B\times(\text{每元素 bytes})$$

（2＝K 與 V 各一份；$L$＝層數、$n_\text{kv}$＝KV head 數。GQA / MQA 讓多個 query 頭共用較少的 KV head，就是為了縮小這一項。）

prefill vs 單步 decode 的 shape（沿用 §15.2 的例子：$h=2$、$d_\text{head}=4$；既有 context 長度 $n$）：

prefill（一次處理 $n$ 個 token）decode 單步（只處理 1 個新 token）
Q[1, 2, n, 4][1, 2, 1, 4]
K、V[1, 2, n, 4]，算完寫入 KV cache新 token 的 [1, 2, 1, 4] 接到 cache 後 → [1, 2, n+1, 4]
注意力分數 $QK^\top$[1, 2, n, n][1, 2, 1, n+1]
注意力輸出（concat 後）[1, n, 8][1, 1, 8]
LM head logits[1, n, |V|]（生成只用最後一個位置）[1, 1, |V|]

工程意涵。 prefill 階段運算密集、較常受算力限制；decode 階段每步計算量小，但要讀取全部權重與 KV cache，較常受記憶體頻寬限制。長 context 同時推高 prefill 的計算量與 KV cache 的記憶體需求——這是 LLM 推論需要大容量、高頻寬記憶體的主因之一。

16. 自迴歸生成與取樣

LLM 怎麼「生成」？——逐字接龍（自迴歸）：每步用前文預測下一個 token 的機率分布（對整個詞表做 softmax，§3.3），選一個、接回輸入、再預測下一個，重複。

  • 本質：生成 = 一連串「對詞表的分類」（見姊妹文件 ai-background-knowledge 的 1.1）。
  • 取樣策略（怎麼從機率分布選字）：greedy（取最高＝argmax，穩定但單調）、temperature（溫度）（高溫發散有創意、低溫保守穩定）、top-k / top-p (nucleus)（只從前 $k$ 個 / 累積到 $p$ 的候選取樣，兼顧品質與多樣）。

工程意涵。 生成是逐 token 串行（每個 token 一次前向）→ 慢；用 KV cache 避免重算前文。context 長度上限來自多個因素：模型訓練時使用的長度與位置編碼方式、prefill 階段約 $O(n^2)$ 的注意力計算，以及隨長度線性增長的 KV cache 記憶體（§15.4）。

17. 訓練目標與微調 (Fine-tuning / LoRA)

大模型分兩階段：

  • 預訓練 (pretrain)：用海量無標籤資料 + 自監督目標（LLM = 一直「預測下一個 token」，§15.3、§16）學到通用語言能力。從零訓練通用大型基礎模型通常需要極高的算力與資料成本，多由資源充足的組織執行；但較小的模型、領域模型，以及在既有模型上以領域資料繼續預訓練（continued pretraining），也可能由研究團隊或企業進行。
  • 微調 (fine-tune)：拿預訓練好的模型，用任務 / 領域資料再訓練，適配到目標用途。所需資料量依模型大小、任務難度與訓練方法（全量微調、PEFT，§17.1）而定，從數百筆到大量資料都有可能。

17.1 全量微調 vs 參數高效微調 (PEFT)

  • 全量微調：更新所有參數 → 自由度最高，但吃記憶體/儲存（每個任務存一份完整大模型），且不保證一定優於適當的 PEFT。
  • PEFT（參數高效微調）：只調一小部分參數，省很多。LoRA 是最常用的。

17.2 LoRA（低秩增量）

凍結原權重 $\mathbf{W}$，只學一個低秩增量 $\Delta\mathbf{W}=\mathbf{B}\mathbf{A}$（$\mathbf{B}$ 是 $d\times r$、$\mathbf{A}$ 是 $r\times d$，秩 $r$ 很小，如 8）：

$$\mathbf{W}'=\mathbf{W}+\Delta\mathbf{W}=\mathbf{W}+\mathbf{B}\mathbf{A}$$

  • 為什麼省：原本要學 $d\times d$ 個數，現在只學 $2dr$ 個（$r\ll d$）→ 參數量、記憶體大減，還能多個 LoRA 切換（同一底模型掛不同小增量）。
  • 數學根：接回 §1.3 矩陣乘法——用兩個瘦矩陣 $\mathbf{B},\mathbf{A}$ 把權重更新 $\Delta\mathbf{W}$ 限制為低秩（低秩參數化）。注意這是約束「更新」的秩（假設任務適配所需的改變是低秩的），不是用 SVD 去近似原權重 $\mathbf{W}$。

工程意涵。 LoRA 讓你用小算力把大模型客製化。RAG 與微調解決的是不同問題，別混用：

  • RAG：注入外部、可更新、可追溯的知識（不改模型、外掛知識庫，知識即時可換）。
  • 微調 / LoRA：調整行為、格式、語氣、任務策略與領域適配。
  • 微調也可能吸收一些知識，但不保證準確回憶、可更新性或來源可追溯——要可靠地注入事實、且要能更新 / 查來源，用 RAG。

實務上常兩者並用（RAG 給知識、微調給風格與任務適配）。
