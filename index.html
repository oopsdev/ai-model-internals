先看定位：AI / ML / 深度學習

開始前先建立全景——本教材談的模型落在哪裡：深度學習（多層神經網路）是機器學習的一支，CNN / RNN / Transformer 都是它的架構；而 GBDT / LightGBM 雖是 ML 主力，卻不是神經網路、不算深度學習（附錄 C 專門與 NN 對照）。

AI（人工智慧）
└─ ML（機器學習）
   ├─ Deep Learning（深度學習＝多層神經網路）
   │    ├─ MLP（全連接）
   │    ├─ CNN（卷積，影像/空間）        → §11
   │    ├─ RNN / LSTM（序列）             → §14
   │    └─ Transformer（注意力，LLM 骨幹）→ §15
   └─ 非深度學習的 ML
        ├─ 線性/邏輯迴歸                  → §3、§3.2
        └─ GBDT / LightGBM（決策樹集成，不是神經網路 → 不算 DL）→ 附錄 C

「深」＝多層堆疊；單一神經元或單層一般不算深度學習。CNN 天生多層，是標準的 DL 成員。

訓練一個模型在做什麼？（不分 NN 或決策樹的通用定義）

機器學習訓練模型的過程，是先選定一個「模型家族（假設空間，Hypothesis Space）」與衡量模型預測好壞的「損失函數（Loss Function）」；接著利用最佳化或搜尋演算法，根據訓練資料，在假設空間中尋找能讓訓練損失盡可能小的模型，並透過正則化、驗證資料與模型複雜度控制等方法，希望這個模型也能泛化到未見過的資料。

過程中被「學」出來的內容依模型家族而不同，可能是一組連續參數，例如神經網路的權重與偏置 (bias)、線性模型的係數；也可能包含模型結構與規則，例如決策樹選擇哪個特徵、在哪個門檻進行切分，以及每個葉節點應輸出什麼結果。

最後確定下來的模型結構 ＋ 學習得到的參數／規則，就是訓練完成的機器學習模型。

不同模型家族，對到同一個框架：

通用元件神經網路 (NN)決策樹 / GBDT
模型家族 / 假設空間選定的網路架構（層數、維度）樹的集成（受 max_depth / num_leaves 約束）
被學出來的東西連續權重 $\mathbf{w}$、偏置 $b$樹結構（切分特徵＋門檻）＋ 葉值（GBDT 有多棵）
怎麼搜 / 最佳化梯度下降 ＋ 反向傳播（§4、§5、§9）貪婪找最佳切點（降不純度 / gain）；GBDT 逐輪加樹擬合負梯度（附錄 C）
特徵常自學新表示（表徵學習，附錄 I.8）用既有特徵、學「挑哪個特徵 / 門檻」
訓練成品架構 ＋ 權重整組樹的結構 ＋ 葉值

共同主軸

選定一個假設空間 H
→ 定義損失／目標函數
→ 利用訓練資料與最佳化／搜尋演算法在 H 中尋找適合的模型
→ 透過 Validation / Regularization 等方法控制泛化能力
→ 固定模型並用於未來資料的預測。

其中，假設空間 H（Hypothesis Space）就是「模型被允許搜尋的所有候選函數或規則的集合」。

因此，機器學習訓練的核心可以簡化為：

先限制模型可以從哪一群答案中尋找（Hypothesis Space），再定義什麼叫做「好答案」（Loss / Objective），最後利用資料找出其中表現最佳的模型。

我該從哪裡開始？

本文從線性代數一路到 CNN / Transformer / 量化 / GBDT，內容完整但長。不用從頭讀到尾——先選你的學習目標、按推薦順序讀；完整章節見下方目錄。（不熟的縮寫如 CNN／Transformer／GBDT，見下方縮寫對照表。）

章號不等於閱讀順序：章節依主題分類（數學 → 訓練 → 架構 → 評估 → 部署），方便查閱；第一次從頭學，請走路線 0，不需前後跳。

🌱 0：第一次順讀（初學者）

適合：第一次系統學 NN。章號是查閱用的分類，照這條順序讀就不必來回跳。

  1. 單一神經元：$z=\mathbf{w}^\top\mathbf{x}+b$
  2. 激活函數：加入非線性
  3. 多層前向傳播：逐層算出預測
  4. 損失函數：怎麼知道錯多少
  5. 鏈鎖律：梯度如何層層相乘
  6. 反向傳播：算出每層的梯度
  7. 梯度下降 / Adam：用梯度更新參數
  8. 初始化與正規化層、正則化：訓練得穩、避免過擬合

完成後：能從單一神經元一路說明到一個多層網路如何被訓練。

🚀 A：30 分鐘快速理解

適合：想先懂模型如何完成一次預測，不急著看完整推導。

  1. 綜合範例：模型怎麼運作
  2. 前向傳播：如何算出答案
  3. 損失函數：怎麼知道錯多少
  4. 反向傳播：算出每層的梯度
  5. 梯度下降 / Adam：用梯度真正更新參數
  6. Transformer：LLM 如何用注意力（選讀）

完成後：能描述「輸入 → 預測 → 損失 → 梯度 → 參數更新」的完整訓練循環。

📐 B：數學原理

適合：想真正看懂公式、梯度，與模型為何能學習。

  1. 線性代數：向量、內積、矩陣乘法
  2. 機率統計：機率、似然、分布
  3. 迴歸、分類與損失函數
  4. 微積分：導數、梯度、鏈鎖律
  5. 梯度下降與 Adam
  6. 反向傳播推導

完成後：能手算小型模型的前向、損失、梯度與一次參數更新。

🛠️ C：工程選型與部署

適合：要選模型、估算硬體，或部署到中央／邊緣設備。

  1. CNN：影像與局部特徵
  2. RNN/LSTM：時序與串流資料
  3. Transformer：語言與長距依賴
  4. GBDT/LightGBM：表格資料
  5. 評估指標：怎麼判斷模型可用
  6. 數值格式：FP32 / BF16 / FP16 / INT
  7. 量化：模型如何縮小
  8. GPU/NPU：硬體為什麼能加速

完成後：能依資料型態、延遲、記憶體、準確度需求，初步選模型與部署方式。

ML 完整管線 — 每一步對應哪一章

ML 不是只有「訓練模型」——它是一條「資料 → 特徵 → 模型 → 評估 → 部署 → 監控」的迴圈（監控到漂移就回頭重訓，不是一次性直線）。本教材的數學主要落在「特徵 → 模型 → 訓練 → 評估」段；資料段在 附錄 H、特徵在 附錄 I、部署與監控偏 MLOps（著墨較淺）。

⑤ 特徵工程建構/選擇/縮放特徵（相關/不冗餘/尺度）附錄 I、§1.1、§1.5、§1.6

⑦ 訓練初始化→前向→損失→反向→更新 × epoch，配優化器/正則化/早停§10→§7→§3/附錄 F→§9→§5、§6

⑨ 部署（推論）上線只走前向一遍；量化、選硬體§7、§20
⑩ 監控 / 維運偵測分布漂移、效能退化 → 定期重訓附錄 H

三個關鍵觀念。 ① 它是迴圈不是直線：⑩ 監控到漂移 → 回 ②/⑦ 重訓；⑧ 評估不滿意 → 回 ⑤/⑥/⑦ 調整。② 訓練 vs 推論不同：①–⑧ 是訓練期（要資料、標籤、跑完整迴圈）；⑨ 上線只做前向一遍（固定參數、不再反向）——這正是「邊緣做推論、訓練放中央」的由來。③ 教材重心在 ⑤–⑧（數學核心）；②–④（資料）在 附錄 H；①問題定義、⑨部署、⑩監控偏 MLOps/工程，屬另一領域。
