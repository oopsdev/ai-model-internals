附錄 C — 判別式 ML：梯度提升樹 (GBDT / LightGBM)，對照 NN

本教材主體講神經網路，但判別式 ML 的另一大主力是「梯度提升決策樹 (GBDT)」——在表格 / 結構化資料上常是很強的 baseline，訓練與推論成本也常低於 NN（實際優劣仍需在目標資料上比較）。§11.7 提過「表格資料 → 樹模型 (GBDT)」，本附錄補上它並與 NN 對照。先建立適用範圍（C.1）、補齊先備知識（決策樹、集成，C.2），再用手算走完「一棵樹 → 多棵樹 → 分類梯度」（C.3–C.7），並說明 GBDT 為何是「加法模型、但對特徵非線性」（C.6.1）；Autoencoder 於 C.11 case study 就地說明。

C.1 GBDT 解決什麼問題（適用範圍）

  • 輸入：通常是一列列結構化 / 表格特徵（每列一筆樣本、每欄一個特徵）。
  • 輸出：連續數值（迴歸）、二元或多類別（分類）皆可。
  • 不直接吃影像、文字、原始封包——這些要先抽成表格特徵才能餵樹（呼應 §11.7、附錄 I）。
  • 和 NN 學的是同一件事（輸入→輸出的函數），只是表示方式不同：NN 是一組連續權重、用梯度下降反覆微調同一組參數（§4、§5）；GBDT 是一疊離散的樹、逐輪增加新樹來逼近目標。

C.2 先備：一棵決策樹怎麼預測（＋集成）

節點術語。 一棵決策樹由根節點 (root) 出發，每個內部節點問一個「某特徵 vs 門檻」的 yes/no 問題（＝一條 if-else），依答案走左 / 右分支，最後落到葉節點 (leaf) 讀出預測。

packet_count > 1000?
├─ 否 → 正常機率 0.08
└─ 是 → avg_packet_size > 900?
        ├─ 否 → 正常機率 0.35
        └─ 是 → 攻擊機率 0.91

追一筆資料（packet_count=3200, avg_packet_size=1420）：根節點「>1000?」→ 是 → 「avg_packet_size>900?」→ 是 → 葉「攻擊機率 0.91」。一次預測 ＝ 從根走到某個葉。

  • 葉節點存什麼：分類存類別機率 / 多數類；迴歸存葉內樣本的平均值。
  • 樹深 (depth) / 葉數 (leaves) 越大 → 模型越複雜（能切更細，但更易過擬合，C.4）。

集成 (Ensemble)：很多弱樹合成強模型。 兩大流派：

方法樹之間目的
決策樹 (Decision Tree)一棵簡單、好解釋
隨機森林 (Random Forest)多棵並行、投票 / 平均降變異（Bagging）
GBDT / XGBoost / LightGBM多棵串行、每棵修前面的錯降偏差（Boosting，本附錄主角）

C.3 一棵樹怎麼選分裂點（直覺 → 手算 → 公式）

直覺：切一刀，讓左右兩群比切之前更「純」（同一群盡量同類）。手算（6 筆），以 packet_count 分「正常 / 攻擊」：

packet_count1020308090100
label正常正常正常攻擊攻擊攻擊

用 Gini 不純度 $\text{Gini}=1-\sum_c p_c^2$（越小越純）。切之前：3 正常 3 攻擊 → $1-(0.5^2+0.5^2)=0.5$。比較兩個候選門檻：

  • packet_count ≤ 25：左 {10,20}＝2 正常（Gini 0）；右 {30,80,90,100}＝1 正常 3 攻擊 → $1-\big((\tfrac14)^2+(\tfrac34)^2\big)=0.375$。加權 $\tfrac{2}{6}\cdot0+\tfrac{4}{6}\cdot0.375=0.25$ → 下降 $0.5-0.25=0.25$。
  • packet_count ≤ 55：左 {10,20,30}＝全正常（Gini 0）；右 {80,90,100}＝全攻擊（Gini 0）→ 加權 0 → 下降 $0.5$（一刀切乾淨）。

→ 樹選下降最多的 ≤55。一般準則：分類用 Gini / 熵 (entropy) 下降、迴歸用變異數（平方誤差）下降、LightGBM 則用梯度 + Hessian 算增益（C.8、C.9）。

C.4 為什麼單棵樹不夠 → 要集成

  • 深樹會「背答案」：切夠深可完美記住訓練資料 → 過擬合、對新資料差。
  • 不穩：資料稍變，樹結構可能大變（高變異）。
  • 淺樹偏差高、深樹變異高，單棵難兩全 → 需集成（C.2 表）。GBDT 走 Boosting：不是並行投票，而是一棵接一棵修正殘餘的錯（C.5）。與 NN 的根本差異：NN 調同一組連續權重、GBDT 逐輪加離散的樹（兩者都用到「梯度」概念，§4）。

C.5 GBDT 如何逐輪修正錯誤（兩輪手算）★本章核心

核心一句：第一棵抓大方向，之後每一棵專門補「目前還差多少」。GBDT 的迴圈：

用三筆迴歸資料走兩輪（學習率 $\eta=0.1$）。真值 $y$：A=10、B=20、C=30；起始預測取平均 $F_0=20$。第 1 輪——先看差多少（殘差 $r=y-F$），再長一棵小樹擬合殘差：

樣本$y$$F_0$殘差 $r$
A1020−10
B20200
C3020+10

假設這棵 depth-1 小樹切成 {A} 與 {B,C} 兩葉，葉值＝該葉殘差平均：$h_1(\text{A})=-10$、$h_1(\text{B})=h_1(\text{C})=\tfrac{0+10}{2}=5$。更新 $F_1=F_0+\eta\,h_1$：$F_1(\text{A})=20+0.1(-10)=19$、$F_1(\text{B})=F_1(\text{C})=20.5$。

第 2 輪——用新的殘差 $r_2=y-F_1$ 再長一棵：

樣本$y$$F_1$殘差 $r_2$
A1019−9
B2020.5−0.5
C3020.5+9.5

小樹切 {A} 與 {B,C}：$h_2(\text{A})=-9$、$h_2(\text{B})=h_2(\text{C})=\tfrac{-0.5+9.5}{2}=4.5$。更新得 $F_2(\text{A})=18.1$、$F_2(\text{B})=20.95$、$F_2(\text{C})=20.95$。

損失（殘差平方和 SSE）逐輪下降：$F_0$：$10^2+0+10^2=200$ → $F_1$：$9^2+0.5^2+9.5^2=171.5$ → $F_2$：$8.1^2+0.95^2+9.05^2\approx148.4$。A、C 的預測正緩緩爬向 10、30。這就是 boosting「boost」的東西：一輪一輪把剩下的誤差往下壓；$\eta$ 越小 → 每步越保守、要越多棵，但通常更穩（調參時的權衡）。

C.6 從殘差推廣到「負梯度」

上面「擬合殘差」只是平方損失下的特例。一般而言，每一輪的新樹擬合的是負梯度：

$$r_{im}=-\left[\frac{\partial L\big(y_i,F(x_i)\big)}{\partial F(x_i)}\right]_{F=F_{m-1}}$$

白話：對某筆資料問「把它目前的分數調高一點，損失會不會下降？」——會 → 這輪新樹對它輸出正修正；反之輸出負修正。「Gradient Boosting」的名字就來自在函數空間裡沿負梯度方向、一棵一棵加樹。

  • 平方損失 $L=\tfrac12(y-F)^2$：$-\partial L/\partial F=y-F$ ＝普通殘差（所以 C.5 直接用殘差）。
  • 換損失就換目標：如分類用的對數損失，負梯度不再等於普通殘差（見 C.7）——別把「殘差」與「負梯度」畫等號。
  • 一階 vs 二階：上式是經典 GBM（Friedman）的基本形式——新樹擬合負梯度，再算葉值（Friedman 處理 logistic 損失時，葉值已用一步牛頓近似）。XGBoost / LightGBM 則把損失的二階泰勒近似同時用在分裂增益與葉值：用梯度 $g_i$ 與 Hessian（二階導）求得葉值 $w=-G/(H+\lambda)$（C.9），相當於在每片葉子上走一步牛頓法 (Newton step)。學習率 $\eta$ 的角色是 shrinkage（收縮係數）：把每棵樹的貢獻再打折，換取更穩的泛化。（符號提醒：C.9 的 Hessian $h_i$ 以樣本 $i$ 為下標，第 $m$ 棵樹 $h_m$ 以輪次 $m$ 為下標，兩者不同。）
  • 每輪看的是全部樣本：新樹擬合的是所有樣本的梯度；誤差大的樣本梯度大，對切分與葉值的影響也大，但不是「只挑錯的樣本來學」。這和 AdaBoost「調高錯誤樣本權重」的做法不同。（LightGBM 的 GOSS 依梯度大小抽樣，是加速手段，見 C.8。）

C.6.1 加法模型 ≠ 對特徵線性

GBDT 的最終模型是各樹輸出的加總：

$$F_M(x)=F_0+\eta\sum_{m=1}^{M}h_m(x)$$
  • 疊加方式是線性的：每輪 $F_m=F_{m-1}+\eta\,h_m$ 只是把一個修正函數加進來，所以 GBDT 屬於加法模型 (additive model)。
  • 對特徵 $x$ 是非線性的：每棵樹是分段常數函數（if-else 分支，同一葉內輸出同一個值），分段常數函數相加仍是分段常數函數。樹與切點足夠多時，能表達彎曲、非單調的關係；精細程度受資料量、分箱數（max_bin）、樹深與正則化限制。
  • 特徵交互：深度 > 1 的樹在同一條路徑上串接多個條件（例如「溫度 > 78 且 負載 > 90%」），因此有能力表達特徵交互；實際是否學到，取決於資料與分裂增益。深度 = 1（stump）時每棵樹只看一個特徵，模型退化為 $\sum_j g_j(x_j)$，類似 GAM（廣義加法模型），沒有交互。
  • 變體：LightGBM 的 linear_tree=True 在葉內改放線性模型，整體成為分段線性，仍不是整體線性。

幾何意義：線性模型在特徵空間裡是一個平面（只有一個特徵時是一條直線，斜率處處相同）；GBDT 是許多階梯疊出來的曲面——每棵樹在切點處跳一階，疊加後階梯變細，逐步貼近彎曲的真實關係。

面向線性模型 / 人工加權GBDT
模型形式$\sum_i w_i x_i+b$$F_0+\eta\sum_m h_m(x)$
加總的對象特徵（各乘一個固定權重）樹（每棵都是非線性函數）
權重 / 門檻來源人定；或由線性 / 邏輯迴歸從資料學不設逐特徵權重；分裂與葉值由損失函數在資料上逐輪貪婪決定
特徵從 30→40 與 80→90對預測的影響必定相同（邏輯迴歸指 logit 尺度）可以不同
特徵交互需手動加交叉項樹深 > 1 時有能力表達
解讀方式係數直觀；但特徵相關或尺度不同時，不能直接當重要性或因果需事後分析：feature importance（無方向）、SHAP / partial dependence（有方向）

一句話：線性模型是把特徵線性組合；GBDT 是把非線性的樹線性組合。

C.7 二元分類內部怎麼運作

分類時，所有樹加總得到的 $F(x)$ 不是機率，而是 raw score（logit）；再用 sigmoid 轉成正類機率 $p=\sigma(F)=\tfrac{1}{1+e^{-F}}$（§3.2）。對數損失 (BCE) 對 logit 的梯度很乾淨：

$$g_i=\frac{\partial L}{\partial F}=p_i-y_i\quad\Rightarrow\quad\text{負梯度}=y_i-p_i$$

所以新樹擬合的是 $y_i-p_i$（XGBoost / LightGBM 另用 Hessian $p_i(1-p_i)$ 算葉值，見 C.6）。起始值 $F_0$ 不再取平均，而常取訓練集正類比例 $\bar p$ 的 log-odds：$F_0=\log\frac{\bar p}{1-\bar p}$。直覺：

情況$y$目前 $p$負梯度 $y-p$新樹該做
正類卻信心不足10.5+0.5拉高 logit
負類卻信心太高00.5−0.5壓低 logit
已答對且很有信心10.95+0.05幾乎不動

（呼應 §3.2：sigmoid + BCE 的梯度也是「預測減真值」$\hat y-y$——GBDT 與邏輯迴歸在這點同源，只是一個加樹、一個調權重。）

C.8 LightGBM 的四個加速關鍵（微軟的 GBDT 實作）

  • Histogram（直方圖分箱）：連續值先分成有限個 bins、只看箱邊界當候選切點 → 快又省 RAM（代價：近似切點，受 max_bin 影響）。
  • Leaf-wise（逐葉生長）：每次分裂「當下增益最大」的葉（不像傳統 level-wise 逐層長）→ 同葉數下通常更快降損失（風險：leaf-wise 生長若缺少複雜度限制，尤其在資料較少時容易長太深而過擬合；用 num_leaves / max_depth / min_data_in_leaf 控制）。
  • GOSS（單邊梯度採樣）：全留誤差大的樣本、只抽樣容易的 → 算力集中在難點。
  • EFB（互斥特徵綁定）：把幾乎不同時出現的稀疏特徵綁一起 → 降有效維度。
  • 效能：大資料常明顯較快、記憶體較省；但實際速度取決於資料量、稀疏性、特徵數、超參數、硬體與版本，應以目標資料 benchmark，不宜套固定倍數。與 XGBoost 等其他實作的準度高低，同樣需在目標資料上以相同驗證流程比較。

C.9 用到的數學運算（不需矩陣乘法）

LightGBM 不像 NN 靠矩陣乘法 (matmul)，核心是統計累加 + 純量算術 + 比較——這是它在多數中小型情境下 CPU 就足夠的主因；GPU 能帶來多少收益需實測（見本節末）。

運算是什麼類型
梯度 / Hessian每樣本算損失一階 $g_i$、二階 $h_i$逐樣本純量（2 階泰勒近似）
直方圖建構每特徵分箱、累加每箱 $\sum g$、$\sum h$加總（主要計算量）
分裂增益每候選切點算增益、挑最大純量算術
葉值$w=-G/(H+\lambda)$純量除法
更新$F_m=F_{m-1}+\eta\,h_m$逐樣本純量加法
分箱 / 比較找切點比大小比較 / 排序

分裂增益：$\text{Gain}=\frac12\left[\dfrac{G_L^2}{H_L+\lambda}+\dfrac{G_R^2}{H_R+\lambda}-\dfrac{(G_L+G_R)^2}{H_L+H_R+\lambda}\right]-\gamma$（$G,H$＝該側樣本的梯度、Hessian 總和），全是純量加減乘除。

有向量、無矩陣乘法：梯度陣列、直方圖陣列是「向量 / 陣列」資料，但運算是逐元素累加 + 純量算術 + 比較，沒有 §1.3 那種矩陣×向量 / 矩陣×矩陣乘法。→ 瓶頸偏在記憶體存取而非乘加 (FLOPs)，所以多數中小型表格情境 CPU 就夠、GPU 效益相對有限（LightGBM／XGBoost 亦有 GPU 版；GPU 能帶來多少收益，依實作、資料量、特徵數、分箱設定、CPU↔GPU 資料傳輸與硬體而異，需實測；對照 NN 的 matmul 高度受益於 GPU/NPU，§20）——這也是網路 AI 邊緣 ML 常選 GBDT 的一項考量。

C.10 對照神經網路（何時用哪個）

面向GBDT (LightGBM)神經網路
最適資料表格 / 結構化影像 / 文字 / 序列
大資料速度常較快（視資料 / 實作 / 硬體）相對慢、且高度依賴 GPU
記憶體 / 模型大小通常較小（常見數 MB～數十 MB，隨樹數 / 深度變動）通常較大
邊緣部署很友善（CPU）需 NPU / 量化（§20）
可解釋性較易分析（feature importance、SHAP），但沒有單一權重可直接讀通常較難，需專門解釋方法
不吃原始序列 / 影像（需先抽特徵）—

選型時要確認的條件（不是「表格就一定用 GBDT」）：

  • 資料量：樣本少時兩者都易過擬合，GBDT 需限制 num_leaves / max_depth / min_data_in_leaf；資料極大且有原始序列 / 影像時，NN 的表示學習較有優勢。
  • Early stopping：以 validation set 監看損失，停在不再改善的輪數（§6.2），比手動固定樹數可靠。
  • 類別特徵：LightGBM / CatBoost 可原生處理類別特徵；高基數類別仍要注意過擬合與目標洩漏（附錄 H、附錄 I）。NN 通常改用 embedding（§13）。
  • 缺值：多數 GBDT 實作在分裂時會學缺值該走哪一側；NN 通常需先補值或加缺值指示特徵。
  • 延遲與部署：推論延遲隨樹數、樹深增加，需在目標硬體實測；NN 依模型大小、量化與加速器而定（§20）。
  • 可解釋需求：若需逐筆說明原因，GBDT + SHAP 常較容易落地，但仍不等於因果（附錄 I）。

C.11 Case study：網路入侵偵測 (IDS) / 流量分類

  • 問題：從流量特徵判斷「正常 vs 攻擊（哪一類）」。
  • 特徵：flow 統計（封包大小、時序、上下行量…）——即 §11.7 / nfstream 產出的表格特徵；資料集 NSL-KDD、UNSW-NB15、CICIDS2017。
  • 實證架構：
    • LightGBM + Autoencoder：AE 壓縮/降噪 → LightGBM 分類，在標準資料集上可達很高的準確率。（Autoencoder 自編碼器：用神經網路把輸入壓縮成精簡表示再重建，藉此學到降噪 / 低維特徵；此處當 LightGBM 的前處理特徵抽取器。屬 NN 的一種，教材主體未涵蓋。）
    • 1D-CNN + LightGBM（混合）：1D-CNN 抽特徵、LightGBM 當分類器——DL 抽特徵、GBDT 做決策，兩者互補。
  • 為何選它：流量特徵本質是表格型 → 樹模型擅長；訓練快、推論輕、CPU 就能跑、模型小 → 適合邊緣即時（呼應判別式 ML 的邊緣部署）。

數字要謹慎看（本文只作定性示意）。 資安資料集常因類別不平衡、資料洩漏 (data leakage)、train/test 切法而容易得到異常高的 accuracy。引用任何準確率務必附資料集、train/test split、二元/多類定義、是否處理不平衡與洩漏、是否只看 accuracy（還是 precision/recall/F1）、原始論文來源——否則「漂亮的精確數字」反而降低可信度。此處只說明「GBDT 適合流量表格分類」的定性結論，不以特定數字為準。

常見誤解（GBDT 版）。

  • GBDT 不是用反向傳播訓練樹——是逐輪加一棵樹擬合負梯度（C.5、C.6）。
  • 殘差 ≠ 負梯度：只有平方損失下兩者才相等（C.6）。
  • 新樹不是只學錯的樣本：它擬合全部樣本的梯度，誤差大的影響較大（C.6）。
  • 加法模型 ≠ 線性模型：樹之間是相加，但每棵樹對特徵是非線性的（C.6.1）。
  • 樹加總的 $F(x)$ 是 raw score / logit、不是機率，要過 sigmoid / softmax 才是機率（C.7）。
  • 特徵重要度 ≠ 因果；高度相關的特徵會互相分攤重要度。
  • LightGBM 不保證一定比 XGBoost 快（視資料 / 硬體 / 版本，C.8）。
  • 「樹不需特徵正規化」不代表可以忽略資料品質與資料洩漏（附錄 H）。

C.12 小結

NN 不是萬能：表格資料應把 GBDT（如 LightGBM）列入優先比較，影像 / 序列則多用 DL；兩者也可混合（DL 抽特徵 → GBDT 分類）。判別式邊緣部署（流量分類、異常偵測）中，LightGBM 是值得優先建立的 baseline 之一，最終選擇仍依 C.10 的條件與目標資料上的驗證結果。侷限：對特徵工程敏感；leaf-wise 生長若缺少複雜度限制，尤其在資料較少時容易過擬合（需調 num_leaves / max_depth / min_data_in_leaf / 正則化並搭配 early stopping）；不吃原始序列 / 影像。（本附錄後續可再擴充：傳統 GBDT / XGBoost / LightGBM 的條件式比較表、重要超參數、feature importance 與 SHAP 實作。）

附錄 E — 迴歸分析基礎

主題 3 從「線性迴歸 + 損失」切入，直接談怎麼學參數。本附錄退一步，補上迴歸分析 (regression analysis) 的統計背景：它在做什麼、自變數與應變數的關係、原理，以及常見的迴歸形式。

E.1 迴歸分析在做什麼（意義）

迴歸分析研究兩個或多個變數之間的關係——它們是否相關、相關的方向（正相關 / 負相關）與強度，並據此建立一個數學模型，好讓我們能觀察特定自變數、預測應變數。

  • 核心目標：由給定的自變數，估計應變數的條件期望值 $E[y\mid x]$——也就是「在 $x$ 是這個值的條件下，$y$ 平均會是多少」。迴歸函數本質上就是這條條件平均曲線。
  • 一句話：迴歸 ＝ 找出「$x\to y$ 的平均趨勢」，並用來預測。
  • 注意：迴歸量的是相關與預測，不等於因果（$x,y$ 相關不代表 $x$ 造成 $y$；常見誤區）。

E.2 自變數與應變數的關係（定義）

  • 自變數 (independent variable，又稱預測變數 / 特徵 feature) $x$：輸入、用來解釋或預測的變數。
  • 應變數 (dependent variable，又稱反應變數 / 目標 target) $y$：輸出、被預測的量；它的值「依賴」自變數。

兩者的關係寫成：

$$y = f(x) + \varepsilon$$

其中 $f(x)$ 是迴歸函數（系統性、可預測的部分，$f(x)=E[y\mid x]$），$\varepsilon$ 是隨機誤差（雜訊、量不到的因素，平均為 0）。迴歸就是從資料估計出 $f$。相關的方向與強度常用兩個量描述：相關係數 $r$（$-1\sim1$，正負表方向、絕對值表線性相關強度）、決定係數 $R^2$（模型解釋了應變數多少比例的變異，§18.2）。

E.3 迴歸分析的原理

原理一句話：目的在於找出一條最能代表所有觀測資料的函數曲線——稱為迴歸估計式（迴歸方程） $\hat y=f(x)$；用這條曲線代表應變數（因變數）與自變數之間的關係，再據以預測。具體分四步：

  1. 假設關係形式：先設定 $f$ 的形態（直線、多項式、多變數線性…），留下待定的參數（如 $\mathbf{w}, b$）。
  2. 用資料擬合參數：調參數讓模型最貼合資料——通常最小化殘差平方和（＝最小平方 / MSE，§3.1）。在「誤差服從高斯分布」假設下，這等價於最大似然（附錄 D）。
  3. 預測：把新的自變數代入擬合好的 $f$，得到 $\hat y$，即估計的 $E[y\mid x]$。
  4. 評估：看 $R^2$、殘差圖、參數顯著性，判斷模型好壞與是否過擬合（§6、§18.2）。

E.4 常用的迴歸形式

形式模型用途 / 特性
線性迴歸（單變數 simple linear）$\hat y = wx + b$一個自變數、一條直線；最基本，看單一因子與 $y$ 的線性趨勢
複迴歸 / 多元迴歸（multiple linear）$\hat y = w_1x_1+\dots+w_nx_n+b=\mathbf{w}^\top\mathbf{x}+b$多個自變數同時影響 $y$（房價 ＝ 坪數 ＋ 地段 ＋ 屋齡…）；就是內積 ＋ 偏置，神經元的線性部分（§1.2）
多項式迴歸（polynomial）$\hat y = w_0+w_1x+w_2x^2+\dots+w_dx^d$描述彎曲（非線性）趨勢；雖對 $x$ 非線性，但對參數仍是線性，可用同一套最小平方求解。次數 $d$ 太高易過擬合（§6）
  • 線性迴歸：關係接近直線時最簡潔、可解釋性高。
  • 複迴歸：真實問題多半多因子，這是最常用的形式；也正是本教材「$\mathbf{w}^\top\mathbf{x}+b$」的由來。
  • 多項式迴歸：資料呈曲線時，用高次項把「直線」彎起來；本質是把 $x,x^2,\dots$ 當成新特徵餵給複迴歸（特徵工程的雛形）。
  • 延伸：輸出改成「機率」就是邏輯迴歸（分類，§3.2）；用「多層 ＋ 非線性 $\sigma$」達成更一般的非線性迴歸，就是神經網路（§1.2、§7、§8）。

E.5 與本教材的銜接

迴歸分析是判別式監督學習的統計根基：線性 / 複迴歸 → 主題 3、神經元的線性部分（§1.2）；對參數最小平方 ＝ 高斯誤差下的 MLE → 附錄 D、§2.3；非線性迴歸 → 神經網路用「多層堆疊 ＋ $\sigma$」逼近任意 $f$（§1.3.1、§7）；評估 → $R^2$／MSE 等迴歸指標（§18.2）。

附錄 H — 資料來源、採樣與資料可信度

前面各章講「模型與數學」；但實務上 「garbage in, garbage out」——資料的來源、品質與採樣，往往比模型更關鍵（近年所謂 data-centric AI 的精神）。本附錄補上這塊：資料可信度分級、品質維度、採樣與常見資料陷阱。散見的 §1.1（洩漏）、附錄 C（資安資料集數字要謹慎）、§6（驗證）在此收攏。

H.1 資料可信度分級（三種常見框架）

(a) 標註可信度（ML 標籤層級） — 標籤怎麼來、多可信：

層級怎麼來可信度
Gold（金標）專家標註、多人標註取共識（用 Cohen's / Fleiss' kappa 量一致性）最高，當「真實答案 ground truth」
Silver（銀標）單一標註者、或模型輔助標註再人工複核中，有雜訊
Bronze / 弱標註程式規則、遠距監督 (distant supervision)、heuristic 自動打標低，雜訊大但量多

(b) 資料工程分層（Medallion 架構） — 資料「加工程度」：Bronze 原始擷取（raw、as-is，未清洗）；Silver 清洗/驗證/去重/格式統一後；Gold 聚合、商業/特徵就緒（feature-ready）。

(c) 來源與血緣 (provenance / lineage) — 第一方 vs 第三方、權威來源 vs 衍生、感測器可靠度；資料血緣要能追溯「這欄從哪來、經過哪些轉換」（出問題才查得到、也才防得了洩漏）。

H.2 資料品質維度 (data quality dimensions)

實務常用這幾個面向檢核（DAMA 類）：正確性 (accuracy)、完整性 (completeness，缺值多不多)、一致性 (consistency，不同來源不打架)、時效性 (timeliness，夠不夠新)、有效性 (validity，符合格式/範圍)、唯一性 (uniqueness，不重複)、代表性 (representativeness，樣本像不像母體/上線分布)。其中代表性對 ML 最致命——訓練資料若不像上線資料，模型再準也會垮（見 H.4 分布漂移）。

H.3 採樣 (sampling)

  • 採樣方法：簡單隨機、分層 (stratified，保持類別比例)、系統、叢集。切訓練集常用分層以維持類別分布。
  • 類別不平衡（如 99% 正常、1% 惡意）：過採樣（少數類複製/合成，如 SMOTE）、欠採樣（多數類抽少）、或類別權重（損失對少數類加權）。呼應 §18：不平衡時 accuracy 會騙人，要看 precision/recall/F1。
  • train / val / test 切分：一般隨機切；時間序列必須「按時間切」（用過去預測未來，不能拿未來資料訓練 → 否則洩漏）；資料少用 k-fold 交叉驗證。

H.4 常見資料陷阱

  • 資料洩漏 (data leakage)：特徵（直接或間接）含了答案 → 準確率假高、上線垮（§1.1、附錄 C）。時間洩漏、用了推論時拿不到的欄位都算。
  • 採樣偏差 (sampling bias)：選擇偏差（只收到某類樣本）、倖存者偏差 (survivorship bias)（只看到活下來的）→ 資料不代表母體。
  • 分布漂移 (distribution / dataset shift)：上線資料分布和訓練時不同（covariate shift、概念漂移），模型隨時間退化 → 要監控、定期重訓。
  • 標籤雜訊 (label noise)：標錯的標籤；弱標註尤其嚴重，需清洗或用抗雜訊訓練。

H.5 一句話

模型只能學到資料裡有的東西：先確保來源可信（分級 gold/silver/bronze、可追溯血緣）、品質達標（尤其代表性）、採樣無偏（分層、處理不平衡、按時間切、防洩漏），數學與模型才有意義。這也是為什麼引用任何準確率都要附「資料集、切法、是否處理不平衡與洩漏」（附錄 C）。

附錄 I — 特徵工程 (Feature Engineering)

§1.1 說「好特徵要相關、有變異、不冗餘、尺度合理」，並提到傳統 ML 靠人工設計挑選特徵。本附錄補上：這些條件怎麼用數學公式量化與檢驗、以及常用的特徵建構與選擇方法。

I.1 特徵工程在做什麼

特徵工程 ＝ 人工把原始資料轉成「對模型有用」的特徵，三件事：建構/轉換（造新特徵）、選擇（挑有用的、丟冗餘的）、縮放（調到可比較）。傳統 ML（線性/邏輯迴歸、GBDT）成敗多半在此；深度學習則把一部分自動化（I.8）。下面每個條件都給可計算的公式。

I.2 相關性：量「特徵與目標有多相關」

  • 皮爾森相關係數 (Pearson $r$) — 量線性相關的方向與強度，$r\in[-1,1]$： $$r_{x,y}=\frac{\mathrm{cov}(x,y)}{\sigma_x\sigma_y}=\frac{\sum_i (x_i-\bar x)(y_i-\bar y)}{\sqrt{\sum_i(x_i-\bar x)^2}\sqrt{\sum_i(y_i-\bar y)^2}}$$ 用於連續特徵 vs 連續目標。$|r|$ 越大越相關；$r\approx0$ 表線性無關（但可能有非線性關係）。
  • 斯皮爾曼 (Spearman $\rho$) — 把 $x,y$ 換成排名再算 Pearson，抓單調（含非線性）關係、對離群值穩健。
  • 互資訊 (Mutual Information) — 抓任意相依（含非線性），$=0$ 才表獨立（呼應 附錄 F 的熵）： $$I(X;Y)=\sum_{x,y} p(x,y)\log\frac{p(x,y)}{p(x)\,p(y)} = H(X)-H(X\mid Y)$$
  • 卡方 $\chi^2$ 檢定 — 類別特徵 vs 類別目標的相依：$\chi^2=\sum\frac{(O-E)^2}{E}$（$O$ 觀測、$E$ 獨立假設下的期望次數）。
  • ANOVA F 值 — 連續特徵 vs 類別目標（比較各類別間 vs 類別內的變異）。

I.3 變異：量「特徵有沒有資訊」

$$\mathrm{Var}(x)=\frac1N\sum_i (x_i-\bar x)^2$$

近零變異（幾乎是常數）的特徵資訊量≈0，直接刪（variance threshold）。

I.4 冗餘 / 共線性：量「特徵之間重不重複」

  • 相關矩陣：對所有特徵兩兩算 Pearson $r$，$|r|$ 很高（如 $>0.9$）的一對 → 其中一個冗餘，可刪一個。
  • 變異數膨脹因子 (VIF) — 用其他所有特徵去迴歸第 $i$ 個特徵、得 $R_i^2$：$\ \mathrm{VIF}_i=\dfrac{1}{1-R_i^2}$。$R_i^2$ 越接近 1（越能被別人線性表示）→ VIF 越大 → 共線性越嚴重（VIF>5\~10 常視為問題）。
  • PCA（§1.6）：特徵分解把相關特徵轉成正交主成分、順便降維。

I.5 尺度：把特徵調到可比較（§1.5）

  • 標準化 (z-score)：$x'=\dfrac{x-\mu}{\sigma}$ → 均值 0、標準差 1（最常用）。
  • Min-Max 正規化：$x'=\dfrac{x-x_{\min}}{x_{\max}-x_{\min}}$ → 壓到 $[0,1]$。
  • 對數轉換：$x'=\log(x{+}1)$ — 壓縮長尾/偏態分布（金額、次數、流量），讓大值不主導。

I.6 特徵建構 / 轉換（造新特徵）

  • 多項式 / 交互特徵：$x_1^2,\ x_1x_2$ — 讓線性模型也能表達非線性/交互（呼應 附錄 E 多項式迴歸）。
  • 分箱 (binning)：連續值切成區間變類別（如年齡 → 青/中/老）。
  • 類別編碼：one-hot、target encoding、或 embedding（§12、§13）。
  • 時間特徵：從 timestamp 抽小時/星期；週期性用 $\sin,\cos$ 編（$23$ 點與 $0$ 點才會相鄰）。
  • 聚合特徵：group-by 後的統計量（每個 IP 的封包數 mean/std/count…）。

I.7 特徵選擇（挑有用的、丟冗餘的）三大類

類別怎麼做特性
過濾法 Filter用 I.2\~I.4 的統計量（$r$、MI、$\chi^2$、變異、VIF）排序挑選與模型無關、快；但沒考慮特徵間組合
包裝法 Wrapper拿模型的驗證表現當標準（遞迴特徵消除 RFE、前向/後向選擇）準但貴（要反覆訓練）
嵌入法 Embedded模型訓練時內建選擇：L1 正則化 (Lasso) 把不重要特徵權重壓成 0（§1.4、§6）；樹模型的特徵重要度（附錄 C GBDT）兼顧效果與效率，實務常用

I.8 深度學習：自動特徵學習（表徵學習）

前面 I.1–I.7 是人工特徵工程；深度學習則用表徵學習 (representation learning) 讓模型自己從原始輸入長出特徵，減少人工。

機制（為什麼網路自己會長出特徵）：不是人告訴它「偵測邊緣」，而是給原始輸入 + 一個損失，梯度下降把權重推成「最能降低損失的特徵偵測器」。每層把輸入換到新座標 + 非線性摺疊（§1.3.1），淺層自學低階（邊緣/角）、深層組合成高階（部件/物件）——某一層的激活值就是那層抽象度的「特徵」；全由損失 + 反向傳播驅動（§9、§10）。取用方式：訓練完拿中間層（常是倒數第二層）的激活向量當學到的特徵，餵下游。

怎麼做 — 三種訓練範式：

  • ① 監督式 end-to-end（有標籤）：整個網路在標好的任務上一起訓（如影像分類）；特徵是副產品，倒數第二層激活即通用特徵向量。標籤足夠時最直接。
  • ② 遷移學習：預訓練 + 微調（§17）— 實務最常用：拿別人在大資料上預訓練好的模型（已具通用表徵），兩種用法——當固定特徵抽取器（凍結骨幹、只訓小 head）或微調（fine-tune / LoRA）。標籤少時的首選，不從零學。
  • ③ 自監督學習 (self-supervised) — 無標籤也能學表徵（現代主力）：從資料自造「假任務 (pretext task)」——
    • 重建 / 遮蔽：Autoencoder（壓成 bottleneck 再重建，瓶頸＝壓縮表徵，附錄 C）、遮蔽預測（BERT 遮字、MAE 遮圖塊）、LLM 下一個 token 預測（§16、附錄 F）；
    • 對比學習 (contrastive)：把「同物不同視角（augmentation）」的表徵拉近、不同物推遠（SimCLR / MoCo；CLIP、word2vec 同精神）。
  • ④ 嵌入層 (embedding, §13)：離散輸入（token / 類別）用可學的查表映射成向量、與模型一起訓 → 學出語意表徵。

什麼時候用 / 不用：該用——高維、非結構化、人工難抽特徵的訊號（影像、文字、語音、原始封包序列）；通常不必優先使用——不需要表徵學習的中小型表格資料（欄位本身已是人造特徵、缺可挖的低階結構，GBDT + 人工特徵工程在這類資料上常與 NN 相當或更好；應以 GBDT 與 NN 在目標資料上的驗證結果決定，附錄 C）。所以 I.1–I.7 的手工特徵工程在傳統 / 邊緣場景依然是核心功夫。

一句話：表徵學習 ＝ 讓「損失 + 反向傳播」自動把原始輸入逐層轉成有用特徵、再取中間層當特徵用；實作靠 監督 end-to-end / 遷移學習 / 自監督 三條路。

I.9 該取多少樣本、留多少特徵？

TL;DR：更多特徵 ≠ 更好。 無關 / 冗餘特徵會帶來維度災難與過擬合，特徵要有資訊、不冗餘、不洩漏，寧缺勿濫；更多樣本通常有幫助但邊際遞減，且前提是資料品質。以下講怎麼判斷「剛好」。

沒有 closed-form 公式能算出「$N$ 筆樣本、$d$ 個特徵剛好」——「剛好」取決於訊號強弱、雜訊、模型容量、類別平衡與目標準確度。但有一套原則性流程，而且「夠不夠」是可以量測的。

經驗法則（起手粗估，非定論）。

對象rule of thumb直覺
樣本 vs 特徵$N \ge 10\times$ 特徵數（或參數量）每個要估的權重都得有幾筆資料撐
邏輯迴歸每個預測變數 $\ge$ 10~20 個少數類事件（EPV）分類看少數類筆數、不是總筆數
每一類別每類至少數十~數百筆不平衡時少數類決定成敗
傳統模型的底線$d \ge N$ 時傳統模型易過擬合（過參數化 + 正則化可例外，見下方 double descent）維度災難

量「樣本夠不夠」→ 學習曲線 (learning curve)。 用 10%、20%…100% 的訓練資料各訓一次，畫驗證分數 vs 樣本數：曲線仍在上升 → 加資料還有用；壓平 (plateau) → 瓶頸在特徵/模型，再多資料無益。這是最直接回答「資料夠了沒」的方法（搭配交叉驗證、外部 / held-out 驗證更穩，§19）。

量「特徵留多少」→ 驗證曲線 (validation curve)。 以特徵數 $d$（或 PCA 維度、top-$k$ 重要特徵）為橫軸畫驗證誤差：$d$ 太小欠擬合、太大過擬合又撞維度災難，取誤差最低的 $d$（偏差-變異的甜蜜點）。兩條曲線都要包在交叉驗證裡取平均（§19）。

維度災難 (curse of dimensionality)。 $d$ 一大，資料點在空間中極稀疏、距離失去意義，需要指數級更多樣本才填得滿；故少而精常勝過多而弱。挑特徵的具體演算法見 I.7，其中最接近「有公式」的是 PCA 保留累積解釋變異達門檻（常用 95%）所需的主成分數，以及 LASSO（L1）自動把無用權重壓成 0（§6）。

統一觀點（古典界，非鐵律）：盯「樣本 / 模型容量」比值。 古典統計學習理論的上界大致是泛化落差 $\lesssim \sqrt{\text{模型容量}/N}$（容量 $\approx$ 參數量 / VC 維度），直覺是 $N$ 要大於有效容量。但這是上界、有前提：現代過參數化深度網路常在參數量遠大於 $N$ 時仍泛化良好（double descent、隱式正則化），與此界的直覺相反。所以比值只是起點直覺、非保證；資料不足時仍以加資料 / 降容量 / 加正則化（§6） 為對策。深度學習的 scaling laws 則是另一條經驗冪律。

少數算得上「公式」的定量法（各限特定前提）：

  • 樣本：檢定力分析 (power analysis)——給定目標效果量、顯著水準 $\alpha$、檢定力（如 0.8），反推最小 $N$（多用於 A/B 測試、臨床）。
  • 特徵：PCA 95% 變異準則（見上）。

實務配方。 ① 領域知識給候選特徵（I.1）→ ② 經驗法則設底線（$N\ge10\times$特徵、每類數十筆）→ ③ 學習曲線看資料夠不夠 → ④ 特徵數掃描 / LASSO / PCA 定 $d$ → ⑤ CV + 正則化收斂（§6 / §19）。

I.10 一句話

特徵工程 ＝ 用數學把原始資料變成好特徵：相關性用 Pearson $r$ / 互資訊、變異用 Var、冗餘用 相關矩陣 / VIF、尺度用 標準化 / Min-Max / log；選擇分過濾（統計量）、包裝（看模型）、嵌入（L1／樹重要度）三類。深度學習把「學特徵」自動化，但表格資料仍靠人工特徵工程 + GBDT。
