附錄 A — 餘弦定律 (Law of Cosines)

內積的代數定義與幾何定義為何相等 (§1.1)？關鍵是餘弦定律。本附錄先給餘弦定律的敘述 (A.1) 與自足推導 (A.2，不使用內積)，再用它證明內積兩種定義等價 (A.3)。

A.1 敘述

三角形三邊長 $a, b, c$，設 $C$ 為邊 $c$ 所對的夾角，則

$$c^2 = a^2 + b^2 - 2ab\cos C$$

  • 是畢氏定理的推廣：當 $C=90^\circ$，$\cos C=0$ → $c^2=a^2+b^2$（畢氏定理）。餘弦定律多了修正項 $-2ab\cos C$。
  • $C \lt 90^\circ$（銳角）→ $\cos C \gt 0$ → $c^2 \lt a^2+b^2$；$C \gt 90^\circ$（鈍角）→ $\cos C \lt 0$ → $c^2 \gt a^2+b^2$。夾角越大，對邊越長。

A.2 推導（座標法，最乾淨）

把夾角 $C$ 放在原點、邊 $b$ 沿 x 軸：$C=(0,0)$、$A=(b,0)$、$B=(a\cos C,\ a\sin C)$。

邊 $c=\lvert AB\rvert$，用距離公式：

$$c^2 = (b - a\cos C)^2 + (0 - a\sin C)^2$$

展開：

$$c^2 = b^2 - 2ab\cos C + a^2\cos^2 C + a^2\sin^2 C$$

因 $\cos^2 C + \sin^2 C = 1$（畢氏恆等式），$a^2\cos^2 C + a^2\sin^2 C = a^2$：

$$\boxed{\;c^2 = a^2 + b^2 - 2ab\cos C\;}\qquad\blacksquare$$

此推導只用了距離公式 + 畢氏恆等式，完全獨立於內積，所以下面 A.3「用餘弦定律證內積」不構成循環論證。（等價作法：從 $B$ 對邊 $b$ 作垂線、用畢氏定理分段相加，結果相同。）

A.3 用餘弦定律證明內積的兩種定義等價

內積有兩個定義 — 代數的「分量乘積之和 $\sum_i a_ib_i$」與幾何的「$\lVert\mathbf{a}\rVert\lVert\mathbf{b}\rVert\cos\phi$」。用 A.2 的餘弦定律可證它們相等。取由 $\mathbf{a}$、$\mathbf{b}$ 與其差 $\mathbf{a}-\mathbf{b}$ 圍成的三角形（夾角 $\phi$）：

(1) 代數展開（純用分量、畢氏）：

$$\lVert\mathbf{a}-\mathbf{b}\rVert^2=\sum_i (a_i-b_i)^2=\sum_i a_i^2-2\sum_i a_ib_i+\sum_i b_i^2=\lVert\mathbf{a}\rVert^2+\lVert\mathbf{b}\rVert^2-2\sum_i a_ib_i$$

(2) 餘弦定律（A.2，三邊 $\lVert\mathbf{a}\rVert$、$\lVert\mathbf{b}\rVert$、$\lVert\mathbf{a}-\mathbf{b}\rVert$，夾角 $\phi$）：

$$\lVert\mathbf{a}-\mathbf{b}\rVert^2=\lVert\mathbf{a}\rVert^2+\lVert\mathbf{b}\rVert^2-2\lVert\mathbf{a}\rVert\lVert\mathbf{b}\rVert\cos\phi$$

兩式左邊同為 $\lVert\mathbf{a}-\mathbf{b}\rVert^2$，右邊相等；消去 $\lVert\mathbf{a}\rVert^2+\lVert\mathbf{b}\rVert^2$ 得：

$$\boxed{\;\sum_i a_ib_i=\lVert\mathbf{a}\rVert\lVert\mathbf{b}\rVert\cos\phi\;}$$

即「分量乘積之和」恰等於「兩向量長度 × 夾角餘弦」 — 代數與幾何兩種內積定義其實是同一件事，這也解釋了為什麼「分量硬乘相加」會等於「量測方向對齊程度」。

附錄 B — 貝氏定理推導

貝氏定理（§2.2）可由條件機率的定義直接推出，不需額外假設。

B.1 從條件機率定義出發

條件機率的定義：

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)}\quad\Rightarrow\quad P(A\cap B)=P(A\mid B)\,P(B)$$

交集是對稱的（$A\cap B=B\cap A$），所以同一個聯合機率也能從另一邊寫：

$$P(A\cap B)=P(B\mid A)\,P(A)$$

兩式左邊相同、右邊相等：

$$P(A\mid B)\,P(B)=P(B\mid A)\,P(A)$$

兩邊除以 $P(B)$：

$$\boxed{\;P(A\mid B)=\frac{P(B\mid A)\,P(A)}{P(B)}\;}$$

換符號 $A\to y$（類別）、$B\to x$（證據 / 特徵）即得 §2.2 的貝氏定理：

$$P(y\mid x)=\frac{P(x\mid y)\,P(y)}{P(x)}$$

B.2 分母 $P(x)$ — 全機率公式（歸一化常數）

分母 $P(x)$ 可用全機率公式攤開成各類別的貢獻：

$$P(x)=\sum_{y} P(x\mid y)\,P(y)\quad(\text{離散})\qquad P(x)=\int P(x\mid y)\,P(y)\,dy\quad(\text{連續})$$

它的角色是歸一化常數：確保所有後驗 $P(y\mid x)$ 加起來 = 1。因此貝氏常寫成「後驗 $\propto$ 似然 × 先驗」：

$$P(y\mid x)\ \propto\ \underbrace{P(x\mid y)}_{\text{似然}}\;\underbrace{P(y)}_{\text{先驗}}$$

直覺回顧：先驗 $P(y)$ 是看資料前的信念，乘上似然 $P(x\mid y)$、再歸一化，就更新成後驗 $P(y\mid x)$（見 §2.2）。

附錄 D — MSE ＝ 高斯誤差下的最大似然（推導）

3.1 說「MSE 其實是『假設誤差服從高斯分布』下的最大似然 (MLE)」。這裡把它推出來——說明為什麼平方誤差不是隨便挑的，而是一個明確機率假設的必然結果。

D.1 假設：誤差服從高斯分布

線性迴歸假設真值 $y_i$ 等於模型預測 $\hat y_i=\mathbf{w}^\top\mathbf{x}_i+b$ 再加上一個隨機誤差 $\varepsilon_i$：

$$y_i = \mathbf{w}^\top\mathbf{x}_i + b + \varepsilon_i,\qquad \varepsilon_i \overset{\text{i.i.d.}}{\sim}\mathcal{N}(0,\sigma^2)$$

也就是誤差平均為 0（模型不系統性偏高或偏低）、變異數固定 $\sigma^2$、各筆資料獨立同分布。等價地說，給定輸入 $\mathbf{x}_i$，真值 $y_i$ 以 $\hat y_i$ 為中心呈高斯分布：

$$y_i\mid\mathbf{x}_i\ \sim\ \mathcal{N}(\hat y_i,\ \sigma^2)$$

D.2 寫出似然

單筆資料的機率密度（高斯 PDF，見 §2.1 表）：

$$p(y_i\mid\mathbf{x}_i)=\frac{1}{\sqrt{2\pi\sigma^2}}\exp\!\left(-\frac{(y_i-\hat y_i)^2}{2\sigma^2}\right)$$

因各筆獨立，整份資料的似然是連乘（§2.3）：

$$L(\mathbf{w},b)=\prod_{i=1}^{N}p(y_i\mid\mathbf{x}_i)$$

D.3 取對數（連乘 → 連加）

連乘難處理，取對數似然（log 單調遞增，最大化 $L$ 等價於最大化 $\log L$）：

$$\log L=\sum_{i=1}^{N}\left[-\tfrac12\log(2\pi\sigma^2)-\frac{(y_i-\hat y_i)^2}{2\sigma^2}\right]=-\frac{N}{2}\log(2\pi\sigma^2)-\frac{1}{2\sigma^2}\sum_{i=1}^{N}(y_i-\hat y_i)^2$$

D.4 對 $\mathbf{w},b$ 最大化 ＝ 對 MSE 最小化

右邊第一項 $-\tfrac N2\log(2\pi\sigma^2)$ 與 $\mathbf{w},b$ 無關（常數）；第二項前面的 $\tfrac{1}{2\sigma^2}$ 是正的常數。所以「調 $\mathbf{w},b$ 讓 $\log L$ 最大」只剩下一件事——讓 $\sum(y_i-\hat y_i)^2$ 最小：

$$\arg\max_{\mathbf{w},b}\ \log L\ =\ \arg\min_{\mathbf{w},b}\ \sum_{i=1}^{N}(y_i-\hat y_i)^2\ =\ \arg\min_{\mathbf{w},b}\ \underbrace{\frac1N\sum_{i=1}^{N}(y_i-\hat y_i)^2}_{\text{MSE}}$$

（除以 $N$ 也是正常數，不影響 $\arg\min$。）

$$\boxed{\ \text{高斯誤差下的最大似然}\ \Longleftrightarrow\ \text{最小化 MSE}\ }$$

D.5 意涵

  • 平方不是任意選的：它直接來自高斯 PDF 指數項裡的 $(y-\hat y)^2$。換一種誤差假設就換一種損失——例如假設誤差服從拉普拉斯分布，MLE 會變成最小化絕對誤差 (MAE, $\sum|y_i-\hat y_i|$)。
  • 呼應「選損失＝做假設」（§3.1、§2.3）：MSE ↔ 高斯、交叉熵 ↔ 類別分布，都是最大似然的特例。
  • $\sigma^2$ 去哪了：它不影響 $\arg\min$（不改變最佳 $\mathbf{w},b$），但會影響對數似然的絕對值；若也要估 $\sigma^2$，對它取偏導＝0 會得到「$\sigma^2$ ＝殘差的平均平方」，正是最小化後的 MSE 本身。

附錄 F — 熵 (Entropy) & 交叉熵 (Cross-Entropy)

§3.2 / §3.3 用交叉熵當分類損失、§2.3 說它是負對數似然。本附錄補上背後的資訊理論：資訊量 → 熵 → 交叉熵 → KL 散度，以及為什麼分類用它。

F.1 資訊量：越意外，資訊越多

一個機率為 $p$ 的事件發生時，帶來的資訊量定義為 $I = -\log p$。

  • 越不可能的事發生，資訊越多（越「驚訝」）：太陽升起（$p\approx1$）→ $I\approx0$（沒新意）；中樂透（$p$ 極小）→ $I$ 很大。
  • 為什麼用 $-\log$：要讓「兩獨立事件一起發生的資訊 ＝ 各自資訊相加」（$-\log(p_1p_2)=-\log p_1-\log p_2$），且機率越小資訊越大。
  • 單位：$\log_2$ → bit；$\ln$（自然對數）→ nat（ML 多用 nat）。

F.2 熵：一個分布的「平均資訊量／不確定性」

把分布 $p$ 的資訊量取期望，就是熵 (entropy)：

$$H(p) = -\sum_x p(x)\log p(x) = \mathbb{E}_{x\sim p}[-\log p(x)]$$

  • 直覺：分布越均勻（越不確定）→ 熵越大；越集中（越確定）→ 熵越小。它量化「這個分布有多不確定／多亂」。
  • 例：公平硬幣 $H=1$ bit（最不確定）；兩面都正的硬幣 $H=0$（完全確定）；公平骰子 $H=\log_2 6\approx2.58$ bits。
  • 用途：量化不確定性；資料壓縮的理論下限（Shannon）——無損編碼平均至少要 $H$ bits/符號。

F.3 交叉熵：用「錯的分布」描述「真實分布」的成本

若真實分布是 $p$，但你以為是 $q$，用 $q$ 去描述 $p$ 的資料，平均成本就是交叉熵：

$$H(p,q) = -\sum_x p(x)\log q(x)$$

  • 直覺：用錯誤的信念 $q$ 去描述真實 $p$，要多付代價。$q$ 越接近 $p$，交叉熵越小；$q=p$ 時最小（＝熵 $H(p)$）。
  • 在 ML：$p$ ＝ 真實標籤（one-hot，如「貓」＝ $[1,0,0]$），$q$ ＝ 模型預測機率（如 $[0.7,0.2,0.1]$）。交叉熵損失 $L=-\sum_k y_k\log\hat y_k = -\log\hat y_{\text{真類}}$——因 $y$ 是 one-hot，只剩「真類機率的負對數」。最小化交叉熵 ＝ 把真類的預測機率推高（§3.2、§3.3）。
  • 例：真實 $[1,0,0]$、預測 $[0.7,0.2,0.1]$ → $L=-\ln 0.7\approx0.357$ nat；預測更準 $[0.99,\dots]$ → $L\approx0.01$。

F.4 KL 散度：交叉熵 − 熵 ＝ 兩分布的差距

$$D_{\mathrm{KL}}(p\,\|\,q)=H(p,q)-H(p)=\sum_x p(x)\log\frac{p(x)}{q(x)}\ \ge 0$$

  • 交叉熵 ＝ 熵 ＋ KL 散度。KL 散度 ＝「用 $q$ 近似 $p$ 多付的成本」＝ 兩分布的不對稱距離（$\ge0$，$p=q$ 時為 0）。
  • 分類時 $p$ 是 one-hot → $H(p)=0$，所以最小化交叉熵 ＝ 最小化 KL 散度 ＝ 讓預測 $q$ 逼近真實 $p$。

F.5 為什麼分類用交叉熵當損失（用途）

  • ＝ 最大似然：$-\log\hat y_{\text{真類}}$ 就是負對數似然（§2.3）。最小化交叉熵 ＝ 最大化「模型給正確答案的機率」——和 MSE＝高斯 MLE（附錄 D）是同一套「損失來自最大似然」的邏輯，只是分類假設類別分布、迴歸假設高斯。
  • 梯度漂亮：softmax + 交叉熵的梯度化簡成 $\hat y - y$（§9 的 $\boldsymbol\delta^{(L)}$），數值穩定又好算。
  • 比 MSE 適合分類：交叉熵對「很有信心卻答錯」懲罰極重（$\hat y_{\text{真類}}\to0$ 時 $-\log\to\infty$），逼模型快速修正；MSE 配 sigmoid 會在飽和區梯度消失、學很慢。
  • 兩種形式：二元用二元交叉熵 BCE（§3.2），多類用交叉熵（§3.3）。

F.6 一句話

  • 熵 ＝ 一個分布的平均不確定性（自己對自己的交叉熵）；
  • 交叉熵 ＝ 用預測分布 $q$ 描述真實分布 $p$ 的平均成本，$=H(p)+D_{\mathrm{KL}}(p\|q)$；
  • 分類最小化交叉熵 ＝ 讓預測機率逼近真實標籤 ＝ 負對數似然的最大似然（§3.2 / §3.3、§2.3）。

附錄 G — 高斯分布密度函數的證明（歸一化常數）

§2.1 的常態分布、附錄 D 的 MSE＝高斯 MLE，都用到高斯機率密度函數 (PDF)：

$$p(x)=\frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

指數項 $e^{-(x-\mu)^2/2\sigma^2}$ 是「鐘形」的來源（離中心 $\mu$ 越遠、機率照平方指數衰減）；前面的 $\dfrac{1}{\sigma\sqrt{2\pi}}$ 是歸一化常數，作用是讓全機率 $\int_{-\infty}^{\infty}p(x)\,dx=1$。本附錄證明這個常數為什麼是 $\dfrac{1}{\sigma\sqrt{2\pi}}$——關鍵是高斯積分。

G.1 核心：高斯積分 $\displaystyle\int_{-\infty}^{\infty} e^{-z^2/2}\,dz=\sqrt{2\pi}$

令 $I=\displaystyle\int_{-\infty}^{\infty} e^{-z^2/2}\,dz$。這個積分沒有初等原函數，但用「平方後轉極座標」的技巧就解得開：

第 1 步——平方成二重積分。 把 $I$ 乘自己（換啞變數 $y$），合成平面上的二重積分：

$$I^2=\left(\int_{-\infty}^{\infty}e^{-x^2/2}dx\right)\!\left(\int_{-\infty}^{\infty}e^{-y^2/2}dy\right)=\iint_{\mathbb{R}^2} e^{-\frac{x^2+y^2}{2}}\,dx\,dy$$

第 2 步——轉極座標。 令 $x=r\cos\theta,\ y=r\sin\theta$，則 $x^2+y^2=r^2$、面積元 $dx\,dy=r\,dr\,d\theta$：

$$I^2=\int_{0}^{2\pi}\!\!\int_{0}^{\infty} e^{-r^2/2}\,r\,dr\,d\theta$$

第 3 步——算積分。 內層對 $r$ 換元 $u=r^2/2$（$du=r\,dr$）：$\int_0^\infty e^{-u}\,du=1$；外層 $\int_0^{2\pi}d\theta=2\pi$。所以

$$I^2=2\pi\times 1=2\pi\quad\Rightarrow\quad \boxed{\,I=\sqrt{2\pi}\,}$$

（$r\,dr$ 這個多出來的 $r$ 是關鍵——它正好讓 $e^{-r^2/2}r$ 有初等原函數，這就是「轉極座標」奏效的原因。）

G.2 代回一般 $\mu,\sigma$，解出歸一化常數

設常數 $C$ 使 $\int_{-\infty}^{\infty} C\,e^{-\frac{(x-\mu)^2}{2\sigma^2}}\,dx=1$。換元 $z=\dfrac{x-\mu}{\sigma}$（$dx=\sigma\,dz$）：

$$\int_{-\infty}^{\infty} e^{-\frac{(x-\mu)^2}{2\sigma^2}}\,dx=\sigma\int_{-\infty}^{\infty} e^{-z^2/2}\,dz\overset{\text{G.1}}{=}\sigma\sqrt{2\pi}$$

所以 $C\cdot\sigma\sqrt{2\pi}=1\Rightarrow C=\dfrac{1}{\sigma\sqrt{2\pi}}$。代回即得

$$\boxed{\;p(x)=\frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{(x-\mu)^2}{2\sigma^2}}\;}$$

歸一化常數證畢——它就是為了把鐘形曲線的面積調成 1（合法機率密度的條件）。

G.3 順帶：$\mu,\sigma$ 的意義

代定義可驗證（$\mu,\sigma^2$ 正是這個分布的期望與變異數）：$\ \mathbb{E}[x]=\int x\,p(x)\,dx=\mu$、$\ \mathrm{Var}(x)=\int (x-\mu)^2 p(x)\,dx=\sigma^2$。所以 $\mu$＝鐘形的中心、$\sigma$＝胖瘦（§2.1）。

注意：這裡證的是「歸一化」，不是「為什麼是鐘形」。 指數裡「負的平方」這個形狀本身是另一回事——它可由最大熵（固定均值/變異數下最不確定的分布）或中央極限定理（大量獨立小效應之和趨近高斯）導出，屬更進階主題。本附錄只證：一旦採用這個形狀，前面的常數必為 $\frac{1}{\sigma\sqrt{2\pi}}$ 才會是合法機率密度。
